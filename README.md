# 🌬️ Breeze Launcher

A lightweight, modern and customizable application launcher for Linux, built with Python and GTK.

Breeze Launcher is designed to feel fast, clean and minimal while still giving you plenty of room to customize the look of your desktop.

## ✨ Features

- 🚀 Fast application launcher
- 🔎 Application search
- 🎨 Customizable themes
- 🪟 Modern glass-inspired UI
- 🖼️ Custom icons
- ⌨️ Keyboard-friendly navigation
- 🐧 Designed for Linux
- ⚡ Lightweight and easy to run
- 🛠️ Simple Python/GTK codebase

## 📦 Requirements

- Linux
- Python 3
- GTK 3
- PyGObject

## 🚀 Installation

Clone the repository:

git clone https://github.com/aditoxic-vibe/breeze-launcher.git
cd breeze-launcher

Run Breeze Launcher:

python3 main.py
